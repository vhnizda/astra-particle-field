# Astra Particle Field

A standalone, offline browser recreation of the interactive Astra particle field seen on OpenAI's GPT-6 Astra page.

## Run

Download or clone the repository, then open `index.html` in a current desktop browser. No build step, server, or network connection is required.

## Controls

- Drag to rotate the field
- Use the arrow keys for keyboard rotation
- Select **↻** to replay the opening animation

## Notes

This is an independent, canvas-based recreation built from the page's publicly delivered scene configuration. It does not include OpenAI's compiled site code, branding assets, or other site content. It is not affiliated with or endorsed by OpenAI.
